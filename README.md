# SlotAnalyzer（ネオアイムジャグラーEX版）

設定ごとのスランプグラフの揺れを調べ、実際のグラフに似たシミュレーションから設定と今後の動きを同定する iOS アプリです。

## 画面

| タブ | 内容 |
|---|---|
| 設定推測 | 総G数・BIG・REG から、設定1〜6の事後確率をベイズ推定で表示 |
| 揺れ分析 | 設定ごとに大量のスランプグラフを作り、差枚の帯（90% / 50%）を重ねて表示。100 / 200 / 500 / 1000 / 2000 / 4000 / 8000G 時点の差枚幅・合算の幅・勝率・設定の的中率を一覧 |
| 検証 | 途中（例：2000G時点）と最終（閉店時）のデータを記録し、途中データからの予測（その後のBIG・REG回数、差枚の増減）が実際と合っていたかを集計。店の設定配分の前提ごとに比べられる。CSVの取り込み・書き出しに対応 |
| 類似グラフ | 現在のG数と BIG/REG を入れ、データカウンターのグラフの写真を指でなぞると（差枚と途中経過は自動で取り込み）、似たシミュレーションを探す。そこから設定の構成比と、今後の差枚の分布（扇形）を表示 |

## Xcode で開く

1. `SlotAnalyzer.xcodeproj` をダブルクリックして開く（Xcode 16 以上）
2. 上部のデバイス選択で iPhone の Simulator を選び、Run（▶）で実行する

`App/` `Logic/` `Models/` `Views/` はフォルダごとプロジェクトに同期されているので、これらのフォルダに置いた .swift ファイルは自動でビルド対象になります。実機で動かすときは、ターゲットの Signing & Capabilities で自分の Team を選んでください。

シミュレーションの生成は **Release ビルドのほうが数倍速い**です。Debug で遅いと感じたら、Scheme の Run を Release に切り替えてください。

## 検証用CSVの形式

1行目は見出し（読み飛ばし）。差枚は空欄でも可。最終データが空欄の行は「未完了」として検証から外します。

```
日付,台番,途中G数,途中BIG,途中REG,途中差枚,最終G数,最終BIG,最終REG,最終差枚
2026-10-07,101,2000,8,6,-350,7400,27,24,620
```

最終のG数・BIG・REGは、その日の合計（途中の分を含む）です。

`SampleData/` に、動作確認用の**架空の**サンプルデータがあります（`make_sample.py` で作成。どちらも10台×30日）。

| ファイル | 店の設定配分 | 本当の設定 |
|---|---|---|
| `sample-validation.csv` | 高設定少なめ（40/25/15/10/6/4%） | `sample-validation-answers.csv` |
| `sample-validation-uniform.csv` | 均等（各1/6） | `sample-validation-uniform-answers.csv` |

```

Logic/SettingEstimator.swift    ベイズ推定による設定推測

Logic/FluctuationAnalysis.swift 揺れ幅の帯・G数ごとの統計・的中率
Logic/PathMatcher.swift         類似グラフ同定と今後の動きの集計
Logic/PredictionCheck.swift     途中データからの予測と実績の比較
Models/ValidationRecord.swift   検証用の記録・端末内保存・CSV
App/BankStore.swift             生成状態をタブ間で共有、バックグラウンド実行
Views/                          3タブの画面
```

## 計算モデル

- **出玉**：1G ごとに BIG（252枚）/ REG（96枚）を抽選します。ボーナス以外の払い出し（小役・リプレイ）は、機械割と期待値が一致するよう1Gあたりの平均値で毎G加算します。ベースはおよそ 40G / 50枚になります。小役の細かい揺れは省いているので、実機よりも短期の揺れがわずかに小さく出ます。
- **設定推測**：BIG・REG の回数を二項分布とみなし、尤度に一様な事前分布を掛けて事後確率を出します。
- **類似グラフ同定**：入力した各点での差枚の差を、その時点の全シミュレーションの標準偏差で割って二乗和を取ります。BIG/REG 回数の差は Poisson 近似で同じ尺度に揃えて加えます。距離が近い順に k 本を選び、それらの設定の内訳と、現在地点からの増減を集計します。

## スペック値

ボーナス確率と機械割は北電子の公表スペックで、各解析サイトの掲載値と一致することを確認しています。ぶどう確率などの小役は公表値ではないため、収録していません。

| 設定 | BIG | REG | 機械割 |
|---|---|---|---|
| 1 | 1/273.1 | 1/439.8 | 97.0% |
| 2 | 1/269.7 | 1/399.6 | 98.0% |
| 3 | 1/269.7 | 1/331.0 | 99.5% |
| 4 | 1/259.0 | 1/315.1 | 101.1% |
| 5 | 1/259.0 | 1/255.0 | 103.3% |
| 6 | 1/255.0 | 1/255.0 | 105.5% |

## 機種を増やすとき

`MachineCatalog` に `MachineSpec` を1件追加し、`BankStore.spec` を選べるようにする（Picker を1つ足す）だけで、全タブがその機種で動きます。AT機は出玉の作り方が違うので、`SimulationBank.generate` に別モデルを追加する必要があります。
